# Hospital Analytics Dashboard (Tableau practice)

A Tableau dashboard for a fictional hospital, built as a practice exercise from a written specification.

Dashboard- hospital-dashboard-practice.png

## Requirements followed
- KPIs: total treatment cost and treatment cost per visit, shown in rupees
- Treemap: treatment cost by department
- Donut chart: number of visits for each visit code
- Line chart: day-wise treatment cost of one department by payment mode, with a department selector that affects only the line chart

## What the dashboard shows (50 sample visits)
- Total treatment cost of ₹438,200, an average of ₹8,764 per visit
- Orthopedics is the highest-cost department (₹125,500), followed by Cardiology (₹95,700)
- OPD-GEN and OPD-DIA are the most common visit codes, with 18 visits each
